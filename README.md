# Mini ERP CRM Project

## Tech Stack

Frontend:
- React + TypeScript
- Vite

Backend:
- Node.js
- Express

Database:
- MySQL/PostgreSQL


## Run Locally

### Frontend

cd Frontend

npm install

npm run dev


### Backend

cd Backend

npm install

npm start


## Environment Variables

Backend:
PORT=
DATABASE_URL=
JWT_SECRET=


## Features

- Login Authentication
- Customer Management
- Product Management
- Inventory
- Stock Movement
- Sales Challan
- Reports Dashboard
